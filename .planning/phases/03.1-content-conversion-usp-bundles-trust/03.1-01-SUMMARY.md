### Made-in-India icon choice

**Chose `MapPin`** over `Flag`. Reasoning:
- `ShieldCheck`, `Leaf`, `Lock` are all compact geometric lucide glyphs. `Flag` carries a horizontal pennant silhouette that disrupts the visual rhythm when placed between `Leaf` and `Lock` in the 4-badge strip.
- `MapPin` is a vertical teardrop silhouette that balances the strip row.
- Documented in `src/components/ui/TrustBadge.tsx` file-header comment. Swap to `Flag` is a one-line change in `iconFor()` if visual review requests it.

## Phase 1 contract subtleties encountered

1. **`iconFor()` exhaustiveness without a `default` branch** — the switch on `TrustBadgeLabel` covers all 4 literal arms. Omitting `default` is intentional: if a future author widens `TrustBadgeLabel` without updating `iconFor()`, tsc fails loud at the return-type level ("Not all code paths return a value"). Adding `default: return ShieldCheck` would silently fall back and mask the widening.
2. **`@ts-expect-error` placement for discriminated-union test** — initial multi-line JSX call placed the directive 4 lines above the actual erroring prop (`evidenceUrl` on line 91), triggering TS7's "Unused '@ts-expect-error' directive" diagnostic. Fix: collapsed the JSX to a single line directly below the directive. Added `// prettier-ignore` to prevent formatter from re-wrapping. (TS 5.x placed JSX-prop errors on the opening tag line; TS 7 places them on the specific prop line.)
3. **`satisfies` type literal preservation on `ctaConfig`** — the Phase 1 `satisfies { ..., bundles: Record<'trial'|'fitness'|'bulk', string> }` constraint was preserved verbatim. Phase 6 overwrites each `bundles.*` string with a Shopify URL without a shape change.
4. **`getCta` single-signature discipline** — resisted the temptation to use function overloads (`getCta('bundles.trial'): CtaDestination; getCta(slot: 'primary'|'secondary'|'nav'): CtaDestination`). Overloads would force every `PrimaryCTA.slot` prop widening in Phase 6 (shopify slot addition). Single-signature with a union-type widening is the sealed-surface pattern.
