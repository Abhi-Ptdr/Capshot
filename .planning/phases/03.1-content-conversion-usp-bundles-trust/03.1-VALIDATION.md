## Sampling Rate

- **After every task commit:** `npx vitest run <just-touched-spec>` OR `npm run test:e2e tests/e2e/<just-touched-spec>.spec.ts` (fast feedback on the file in flight)
- **After every plan wave:** full e2e + CI grep + build. `npm run test:e2e -- --workers=1 && npm run grep:ci && npm run build`. Single-worker is required (Phase 2 Plan 03 execution note).
- **Before `/gsd:verify-work`:** full gate must be green: `npm test && npm run test:e2e -- --workers=1 && npm run grep:ci && npm run build`.
- **Max feedback latency:** ~90s per unit sample, ~45s per single e2e spec, ~4 min for the full gate.
